# Noel Ng'ona — Portfolio

Personal portfolio site, live at https://noel-ngona.github.io

It is a single static page: `index.html` plus `noel.jpg`. To change the content, edit the
`PROJECTS`, `FOCUS`, `ROLES`, `EXPERIENCE`, `EDUCATION` and `SKILLS` lists near the bottom of
`index.html`, then commit and push. GitHub Pages republishes within a minute.
